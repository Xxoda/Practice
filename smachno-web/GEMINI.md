# СМАЧНО (Smachno) - Food Delivery App

## Project Overview
Mobile-first web application for food delivery, built with SvelteKit and Tailwind CSS.
The app focuses on a minimalist, monochrome aesthetic with handwritten accents.

## Tech Stack
- **Framework**: SvelteKit (via `sv create`)
- **Styling**: Tailwind CSS
- **State Management**: Svelte Stores + LocalStorage
- **Data**: JSON-based local menu structure
- **Language**: TypeScript

## Features
- **Responsive UI**: Optimized for mobile (360x800) but works on desktop.
- **Menu System**: Categories, Dishes, Modifiers (Size, Add-ons).
- **Cart**: Persistent cart with quantity management.
- **Checkout**: Form with validation and delivery zone logic.
- **WhatsApp Integration**: Orders are sent via WhatsApp message.

## Setup
1. `npm install`
2. `npm run dev`
